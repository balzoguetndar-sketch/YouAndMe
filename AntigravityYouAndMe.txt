2. DIAGNOSTIC INITIAL & CORRECTIONS WEBRTC
--------------------------------------------------------------------------------
A. Problèmes rencontrés lors des sessions de test antérieures :
   - Les appels ne passaient pas toujours ou l'audio était inaudible.
   - On voyait une vidéo mais pas l'autre (asymétrie).
   - La sonnerie tournait sans que le correspondant ne décroche.

B. Causes techniques identifiées et réparations apportées :
   1. Négociation SDP WebRTC (Offer / Answer) :
      - Verrouillage via une promesse (mediaReadyPromise) : la réponse SDP n'est
        générée que lorsque les périphériques locaux (caméra + micro) sont
        capturés et attachés au PeerConnection.
   2. File d'attente des candidats ICE (Réseaux 4G / 5G / Wi-Fi) :
      - Mise en place de pendingIceCandidates pour éviter l'erreur InvalidStateError
        lorsque les paquets réseau arrivent avant la description distante.
   3. Politique Autoplay des navigateurs mobiles :
      - Gestionnaire Web Audio API (sound.ts) pour les sonneries entrantes/sortantes.
      - Ajout d'un bouton de secours interactif ("Activer le son") pour forcer le
        déblocage audio sur Safari iOS et Chrome Android.
   4. Autorisations matérielles :
      - Déclaration explicite des permissions CAMERA, RECORD_AUDIO et INTERNET
        dans le fichier AndroidManifest.xml et les métadonnées PWA.

4. GUIDE D'UTILISATION POUR VOS UTILISATEURS
--------------------------------------------------------------------------------

A. Installation sur iPhone / iPad (iOS Safari) :
   1. Ouvrir le site https://www.youandme.cloud dans Safari.
   2. Toucher l'icône Partager (carré avec une flèche vers le haut).
   3. Choisir « Sur l'écran d'accueil » puis « Ajouter ».
   4. L'application You&Me s'ouvre comme une application native sans barre URL.

B. Installation sur Smartphone Android (Chrome / Samsung Internet) :
   1. Ouvrir le site https://www.youandme.cloud.
   2. Cliquer sur le bouton « Installer » affiché dans l'en-tête du site.
   3. L'application est ajoutée à la liste des applications du téléphone.

C. Compilation de l'APK via Android Studio :
   1. Lancer Android Studio sur votre ordinateur.
   2. Ouvrir le dossier : C:\Users\adiop\YouAndMe\android
   3. Menu « Build » > « Build Bundle(s) / APK(s) » > « Build APK(s) ».
